Compact uppercase label pill for categories, status tags, and numbered eje labels. Always rendered as a pill shape (fully rounded).

```jsx
// Eje number badge (accent orange)
<Badge variant="accent">Eje 1</Badge>

// Category in azul
<Badge variant="primary">Gestión hídrica</Badge>

// Sustainability / active state
<Badge variant="verde" size="sm">Activo</Badge>

// Neutral outline
<Badge variant="outline">En revisión</Badge>

// Muted gray for secondary info
<Badge variant="subtle">2026</Badge>
```

Notable variants:
- `accent` — orange, for eje numbers and priority highlights
- `primary` — azul, for categories and plan axes
- `verde` — sage green, for sustainability / active states
- `outline` — transparent with azul border, for neutral tags
- `subtle` / `muted` — gray backgrounds for secondary metadata
